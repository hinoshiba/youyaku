プライバシーポリシー

制定日: 2026年7月8日 ・ 運営者: hinoshiba（個人）

本ポリシーは、hinoshiba（以下「運営者」）が提供するアプリケーション「Youyaku（ようやく）」（macOS 版・iOS 版。以下「本アプリ」）および本サイト（youyaku.hinoshiba.com）における情報の取り扱いを定めるものです。

1. 開発者による情報収集は行いません

運営者は、ユーザーの個人情報・音声データ・入力テキスト・利用状況を一切収集しません。本アプリにテレメトリ・アクセス解析・広告 SDK は含まれていません。運営者がユーザーのデータを受け取るサーバーは存在しません。

2. 音声認識と文章整形は端末内で処理されます

音声認識および LLM による文章整形は、原則としてすべてユーザーの端末内で実行されます。

  • iOS 版: 音声認識は常に端末内（オンデバイス）で実行されます。音声が外部に送信されることはありません。
  • macOS 版: 既定では「オンデバイス認識を優先」がオンであり、音声は端末の外に送信されません。ユーザーがこの設定をオフにした場合に限り、Apple のサーバー音声認識が使用され、音声データが Apple に送信されます。この場合の取り扱いは Apple のプライバシーポリシーに従います。

3. 履歴・設定は端末内にのみ保存されます

入力履歴や設定は、ユーザーの端末内にのみ保存されます。macOS 版の保存場所は ~/Library/Application Support/Youyaku/ です（モデルファイルも同ディレクトリ配下の Models/ に保存されます）。これらのデータはユーザー自身がいつでも削除できます。

4. モデルのダウンロード（Hugging Face への接続）

本アプリで AI モデルをダウンロードする際、モデル配布元である Hugging Face のサーバーに接続します。この通信に伴い、IP アドレスや User-Agent 等の接続情報が同社に送信されます。取り扱いは Hugging Face のプライバシーポリシーに従います。

5. Ollama 連携（macOS 版・任意設定）

macOS 版では、任意設定として外部の推論エンジン Ollama と連携できます。この機能を有効にした場合、整形対象のテキストがユーザーの設定した接続先ホストへ送信されます。既定の接続先はローカル（127.0.0.1）ですが、ユーザーが外部ホストを指定した場合はそのホストへテキストが送信されるため、接続先の管理には十分ご注意ください。

6. 更新の確認とアプリ内アップデート（macOS 版）

macOS 版は、新しいバージョンの有無を確認するため、1日1回を上限に本サイト（youyaku.hinoshiba.com）から更新情報のみを記載したファイル（appcast.xml）を取得します。この通信でアプリからユーザーの情報が送信されることはありません。この機能は設定でオフにできます。

新しいバージョンがある場合、ユーザーが「アップデート」を選んだときにのみ、更新用のディスクイメージ（DMG）を GitHub（github.com）からダウンロードして適用します。この通信に伴い、IP アドレスや User-Agent 等の接続情報が GitHub 社に送信されます。取り扱いは GitHub のプライバシーステートメントに従います。ユーザーの同意なく更新が適用されることはありません。

更新機能の実装には Sparkle を使用しています。Sparkle が備える匿名の利用統計送信機能は無効にしています。

7. 本サイトの配信（GitHub Pages）

本サイトは GitHub, Inc. の GitHub Pages を通じて配信されています。サイトへのアクセスに伴い、IP アドレス等のアクセス情報が同社のシステムを経由し、その取り扱いは GitHub のプライバシーステートメントに従います。運営者がこれらのアクセス情報を個人の特定に利用することはありません。

8. App Store 版のデータ収集申告

App Store で配布される iOS 版は、App Store のプライバシー表示において「データ収集: なし」として申告しています。
