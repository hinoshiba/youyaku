Features

思いついたことを、伝わる言葉に。

話した内容を整え、次の作業へつなげます。

どこでも呼び出し

メニューバーとグローバルショートカットから入力パネルを開き、カーソル位置へ文章を貼り付け。

音声認識と認識辞書

Apple の音声認識を利用。句読点の自動挿入や、専門用語を登録する認識辞書に対応します。

ローカルAIで整形

内蔵の llama.cpp が、フィラーや言い直しを整理し、読みやすい文章へ整えます。

3つの整形モード

「そのまま」「整文」「AI命令化」を切替。文字起こしにも、AIへの依頼文にも使えます。

前提プリセット

使用技術や出力形式など、毎回伝えたい前提を登録できます。

モデルを選んで使う

Qwen3・ELYZA JP・Gemma などのモデルをアプリから取得し、切り替えられます。

続きから再開

長い口述にも対応。途中で中断した場合は、それまでの文字起こしを残して再開できます。

履歴を見直す

文字起こしと整形結果を履歴から確認し、必要な文章を再利用できます。

日本語・英語に対応

表示言語を日本語と英語で切替。音声認識の言語に合わせて整形します。

How it works

呼び出して、話して、確定。

3つのステップで、声から文章へ。

呼び出す

Mac では ⌥Space で入力パネルを表示。iPhone / iPad ではアプリを開き、マイクをタップします。

話す

伝えたいことを自然に話します。音声を止めたら、選んだモードで文章を整えます。

確定する

内容を確認して、Mac ではカーソル位置へ貼り付け。iPhone / iPad ではコピーや共有で使えます。

整った文章を、その場で。

文字起こしと整形結果を確認し、使う文章を決められます。

メニューバーから操作。

モード・モデル・言語・マイク・前提を切り替えられます。

アプリからダウンロードして切替。必要なメモリと応答速度は、モデルや端末によって変わります。

Mac 版のはじめかた

  1. DMG を開き、Youyaku を Applications フォルダへドラッグします。
  2. Youyaku を開き、ホーム画面の手順に沿ってマイクと音声認識を許可します。
  3. 自動貼り付けを使う場合はアクセシビリティも許可し、整形用のモデルを選びます。

プライバシーポリシー

更新日: 2026年9月6日

音声認識と内蔵AIの整形は、既定では端末内で行います。入力履歴と設定は端末に保存され、履歴はアプリから削除できます。開発者は、音声や入力テキストを収集しません。

Mac で Apple のサーバー音声認識を選ぶと音声が Apple に、Ollama 連携を使うとテキストが設定した接続先に送られます。モデルの取得、更新確認、サイト閲覧では各配信元に接続します。

このサイトは表示言語の選択をブラウザに保存します。App Store の利用や Apple のサービスに関する情報の扱いは、Apple のポリシーをご確認ください。
